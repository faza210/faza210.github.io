Home Server and Self-Hosting

Personal · Jul 2026 to present

I host this site from a Windows PC at home, with the web stack running in WSL (Ubuntu). My home connection sits behind carrier-grade NAT, so nothing on the internet can reach the PC directly. Nginx only listens on the loopback address, and a Cloudflare Tunnel carries the traffic out to Cloudflare, which means no port on my router is open.

Nginx runs as a hardened systemd service with strict security headers and a content security policy. I also set up fail2ban so that repeated failed logins on my private pages turn into IP bans at Cloudflare's edge, and my laptop reaches the PC over a Tailscale network.

On the same machine I run Hermes Agent, an open-source AI agent that I use every day through Telegram. I set up its scheduled jobs and choose which language model handles each kind of task, based on benchmarks I run on them. I also keep a set of local fixes to its source code and carry them across every update.

Hydroponic Grow-Bay Simulator

PRG1203 · Group project (Safelight) · Jul to Aug 2026

A Java console simulation of a hydroponic farm, where grow bays with their own pumps, sensors and nutrient tanks are advanced day by day. Each crop type has its own nutrient, light and pH needs, which the program handles through polymorphism, and planting a crop in an incompatible bay throws a checked exception.

I wrote all of the simulator's code and set up the group's shared repository, working with an AI agent on the program design and the exception handling.
