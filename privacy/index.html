rclone (Google Cloud app)

Private, used by me and my AI assistant

This page covers the app called "rclone" that I registered in Google Cloud under my own Google account. It is a private app, and I do not offer it to anyone else. I use it with rclone, a file copying program, on my own computer to copy and back up files between my Google Drive, my Microsoft OneDrive and my own drives.

An AI assistant that runs on my computer carries out most rclone commands for me when I ask it to. Two Google accounts use the app. One is mine. The other is a Google account that the assistant uses to pass files to me, and I added it to the app myself.

When either account signs in, the app asks Google for full access to that account's Google Drive. This lets it see, edit, create and delete all of its Drive files, Google Docs, Sheets and Slides included. rclone uses this to list, upload, download and delete files when I ask it to. The app does not ask for access to Gmail, Contacts, Calendar or any other Google service.

Files are copied only between my Google Drive, my OneDrive, my computer and the assistant's Google Drive. A file placed in the assistant's Drive is there only so I can download it through a link the assistant sends me. Anyone who has that link can download the file without signing in, and the link does not expire, so the assistant permanently deletes the file once I have confirmed the download. When I name one of my own files on Google Drive or OneDrive, the assistant can also make a link to it. Anyone with that link can open the file until the link is removed.

While it works, the assistant sees the names, sizes and dates of files and folders, the checksums of those files and the messages that rclone and its checking tools print. For photos and videos in a migration I have asked for, it also decodes each file on my computer to check that it opens without errors, and the decoded contents stay on my computer. The assistant sends what it sees to Anthropic, the company whose Claude model it uses, so that the model can work out each step. It reports the results to me in my own Telegram chat. The model receives the contents of a file only when the assistant opens that file for a task I have given it, and those contents then go to Anthropic as well. My Google Drive data is not sold and not used for advertising. Apart from Anthropic, Telegram, which carries the assistant's reports to me, and anyone holding one of the links described above, it is not shared with anyone. If I switch the assistant to another company's model, or ask it to consult one, what it sends goes to that company as well.

The sign-in tokens that rclone receives are kept in one file on my own computer that only its administrator account can read. The assistant runs under that account so that it can use rclone. I can remove the app's access at any time on the third-party connections page of the Google account concerned, and delete the stored tokens from my computer.
