rclone (Google Cloud app)

Private, used by me and my AI assistant

This page covers the app called "rclone" that I registered in Google Cloud under my own Google account. It is a private app and is not offered to anyone else. I use it with rclone, a file copying program, on my own computer to copy and back up files between my Google Drive, my Microsoft OneDrive and my own drives.

An AI assistant that runs on my computer carries out most rclone commands for me when I ask it to. Two Google accounts use the app. One is mine. The other is a Google account that the assistant uses to pass files to me, and I added it to the app myself.

When either account signs in, the app asks Google for full access to that account's Google Drive. This lets it see, edit, create and delete all of its Drive files, Google Docs, Sheets and Slides included. rclone uses this to list, upload, download and delete files when I ask it to. The app does not ask for access to Gmail, Contacts, Calendar or any other Google service.

Files are copied only between my Google Drive, my OneDrive, my computer and the assistant's Google Drive. A file placed in the assistant's Drive is there only so I can download it through a link the assistant sends me, and it is deleted once I have confirmed the download.

While it works, the assistant sees file and folder names, sizes, dates and the messages that rclone prints, and it opens the contents of a file only when a task I have given it needs that. It sends this information to Anthropic, the company whose Claude model it uses, so that the model can work out each step, and it reports the results to me in my own Telegram chat. My Google Drive data is not sold, not used for advertising and not shared with anyone else.

The sign-in tokens that rclone receives are kept in one file on my own computer that only its administrator account can read. The assistant runs under that account so that it can use rclone. I can remove the app's access at any time on the third-party connections page of the Google account concerned, and delete the stored tokens from my computer.
